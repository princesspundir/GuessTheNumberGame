# GuessTheNumberGame
🎯 A Java-based “Guess The Number” console game built using OOP concepts. The program generates a random number between 1 and 100, and the user attempts to guess it with hints like “Too high” or “Too low.” It tracks the number of attempts, providing a simple and interactive gameplay experience.

## 🚀 Features
- Random number generation
- User input handling
- Hint system (Too high / Too low)
- Attempt counter
- Object-Oriented Programming (OOP) implementation

## 🧠 Concepts Used
- Classes & Objects
- Constructors
- Methods
- Encapsulation
- Loops & Conditionals
- Java Scanner & Random classes

## 🎮 How it Works
1. The system generates a random number.
2. The user keeps guessing.
3. The program gives hints after each attempt.
4. Game ends when the correct number is guessed.
